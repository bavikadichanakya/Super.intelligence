# Phase 14.1 — New Visual Direction & Creative Standards

**Brand:** SUPER.INTELLIGENCEEE  
**Motto:** "Understand What's Next."  
**Format:** 1080 × 1920 (9:16 Vertical Documentary)  
**Target Atmosphere:** Premium, cinematic, scientific, authentic, restrained.  

---

## 1. Visual Priorities & Core Philosophy

1. **The Technological Subject is the Hero:**
   - In a documentary about `browser-use`, the hero is the **browser operating system interaction**: the accessibility tree, coordinate tags, multi-step agent decisions, and live execution.
   - The technology must be visually depicted as it actually functions in production engineering, not through decorative mockups.

2. **Environmental & Cinematic Variety:**
   - **Scene 1 (The Problem):** Cinematic macro close-up of a real desktop workstation: hands on a keyboard, a person repeatedly filling repetitive web forms, high-contrast warm desk lighting, natural camera push-in.
   - **Scene 2 (The Discovery):** Full-screen authentic browser viewport showing a complex travel booking interface, transitioning into an autonomous agent prompt bar.
   - **Scene 3 (The Mechanism):** Scientific exploded architectural view: the web DOM tree disassembling into numbered accessibility coordinate tags `[1]`, `[2]`, `[3]`, with the multimodal model decision loop evaluating options.
   - **Scene 4 (Real Demonstration):** Clean modern IDE environment with authentic Python code (`agent = Agent(task=...)`) executing against Chrome DevTools Protocol.
   - **Scene 5 (What Makes It Important):** Macro spatial visualization: AI breaking out of isolated chatbot containers into universal OS actuators.
   - **Scene 6 (Closing Takeaway):** Warm cinematic documentary studio: host delivers final insight with restrained branding.

3. **Character Integration Standards:**
   - The character is a **documentary host and investigator**, not a permanent screen sticker.
   - He appears when narratively justified:
     - Introducing the problem (observing human frustration).
     - Explaining the deep architectural mechanism.
     - Delivering the final takeaway.
   - He steps aside when the code and browser demonstration require full screen attention.

4. **Editorial Typography System:**
   - Large, legible, high-contrast captions centered in safe area (`y=1640..1820`).
   - Clean 2-line maximum with generous letter spacing and zero background clutter.
   - Only meaningful active phrases highlighted.

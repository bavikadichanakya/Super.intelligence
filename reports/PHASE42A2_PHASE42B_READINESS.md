## 3. Phase 4.2B Production Engine Implementation Blueprint

When authorized by human leadership, Phase 4.2B will translate these validated static and motion prototypes into the permanent, automated production renderer for SUPER.INTELLIGENCEEE.

### Module 1: Rebuilt Production Compositor (`core/compositor.py`)
- Retire legacy slide-card templates.
- Implement a modular **Cinematic Scene Engine** capable of rendering three core documentary scene archetypes:
  1. `CinematicAtmosphericScene`: Renders perspective corridor, rack bay silhouettes, animated telemetry LEDs, macro accelerator die with laser engraving, and lower-third typography.
  2. `AlgorithmicMechanismScene`: Renders prompt intake tokens, autoregressive student token rollouts, frozen teacher logit density stems, and dual-branch experimental forks.
  3. `EditorialSynthesisScene`: Renders the monumental display headline, 3-pillar conceptual efficiency matrix, qualified engineering directives, and academic preprint disclosure seal.

### Module 2: In-Memory Video Streaming Pipeline
- Connect the PIL image compositor directly to FFmpeg via `subprocess.Popen(..., stdin=subprocess.PIPE)` using rawvideo RGB24 frames.
- Enforce:
  - Resolution: 1080×1920 (9:16 vertical).
  - Frame rate: 30.0 fps constant.
  - Video codec: `libx264` (YUV420p, CRF 20, preset `fast` or `ultrafast`).
  - Zero disk write overhead for intermediate frames.
  - Memory ceiling: $< 600\text{ MB}$ peak allocation during rendering.

### Module 3: Audio-Visual Synchronization
- Bind Voicebox narration stems (`am_liam` / American voice profile) to scene keyframes.
- Synchronize camera push-ins, token reveals, and card highlights to narration timestamps generated by `core/audio_director.py`.
- Maintain background music ducking ($-18\text{ dB}$ to $-24\text{ dB}$ under speech) and precision SFX hits at scene transitions.

### Module 4: Factual Guardrail Integration
- Integrate an automated factual linter into `core/qa_engine.py`:
  - Scans scene descriptions and narration transcripts for unqualified 50× claims.
  - Verifies that external teacher mentions include the required qualifying clause: *"under matched experimental settings..."*
  - Verifies presence of the Academic Preprint Disclosure seal on concluding scenes.

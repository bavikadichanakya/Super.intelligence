## 3.2 Visual metaphor generation

For each concept, generate several possible visual explanations.

Examples of visual reasoning:

- A GPU memory bottleneck may be explained through a visualized data-transfer pipeline and memory hierarchy.
- A neural network may be explained through connected computational layers and flowing activations.
- A cybersecurity vulnerability may be explained through a controlled architectural attack-path diagram.
- A distributed agent system may be explained through interacting agents and message flows.
- A database index may be explained through a visual search journey.

These are examples of reasoning, not templates to reuse blindly.

Choose a metaphor only if it accurately represents the underlying mechanism.

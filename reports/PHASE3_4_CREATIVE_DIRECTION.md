## 3. Reusable Motion Primitives System

| Primitive | Implementation Technique | Purpose |
| :--- | :--- | :--- |
| **Sub-Pixel Camera Push** | Continuous coordinate interpolation with sub-pixel antialiasing | Draws viewer eye into critical hardware/data regions |
| **Harmonic Spring Scale** | Damped oscillator $f(t) = 1 - e^{-6.5t} \cos(7.5t)$ | Creates natural physical arrival for hero statistics |
| **Mask & Stagger Reveals** | Frame-indexed coordinate thresholding with 15% line offset | Prevents visual overwhelm by staging complex typography |
| **Dynamic Path Signal Pulses** | Travelling circular wave packets along bezier / linear tracks | Visually illustrates continuous associative scan dataflow |
| **Morphing Matrix Collapse** | Linear interpolation from 2D coordinates $(x_i, y_j) \to (x_i, y_0)$ | Visually proves the mathematical collapse from $O(N^2)$ to $O(N)$ |
| **Numerical Value Interpolation** | Progressive numeric ticker with unit suffix | Prevents static data display, showing live measurement |

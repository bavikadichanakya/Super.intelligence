# CREATIVE & VISUAL GUIDELINES — MULTI-ARCHETYPE ENGINE

## 1. Canvas Standard
- **Resolution:** 1080x1920 (9:16 Vertical Instagram Reel & YouTube Short).
- **Frame Rate:** 30.0 FPS.
- **Safe Zone:** Keep critical text and badges at least 220px from top and 340px from bottom (above Instagram handle/caption UI overlay).

## 2. Seven Supported Visual Archetypes
1. `sketch_title`: Dark paper grid (`#22282B`), Caveat bold typography, yellow marker highlight (`#FFD43B`).
2. `sketch_quote`: Golden quotation marks, primary source attribution, lab credential badge.
3. `sketch_stat`: Struck-through baseline (`#E5484D`) with hero multiplier win (`#FFD43B`).
4. `motion_diagram`: 3-stage animated system topology with glowing data paths.
5. `sketch_list`: Sequential numbered item stack with win highlight pill.
6. `product_demo`: Dark CLI terminal window mockup with colored window controls and terminal log output.
7. `stock_broll`: Local CC0 tech footage or photography with subtle gradient overlay.

## 3. Visual Diversity Invariants
- Minimum 3 distinct archetypes across 7 scenes.
- Zero identical consecutive archetypes (`scene[i] != scene[i-1]`).

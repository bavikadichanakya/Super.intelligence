## 1. Visual Storytelling Core Directives

The central requirement of Phase 3.3 is to **stop producing animated slides and start directing visual stories**.

### Core Principles:
1. **The 5-Second Progression Rule:** No scene may hold the same visual arrangement for more than 5 seconds without introducing a new visual discovery, data annotation, structural transformation, or camera refocus.
2. **Phase-Driven Scene Architecture:** Every scene is composed of two distinct narrative phases:
   - **Phase A (The Problem / Mechanism / Context):** Establishes the constraint or foundational state.
   - **Phase B (The Breakthrough / Progression / Impact):** Transforms the visual state to reveal the technical solution or empirical result.
3. **Light-First Warm Ivory Substrate:** Retain `#F7F7F2` warm ivory base with subtle micro-grid, deep charcoal (`#151515`) Swiss typography, and soft elevated card shadows. Dark consoles or silicon dies are used only where source material dictates.
4. **Purposeful Visual Actions:** Every motion element must represent an authentic computer science process (e.g. token streaming, associative scan accumulation, cache tile pinning, memory wall saturation).
